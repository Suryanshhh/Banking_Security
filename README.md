# 🏦 Bank Transaction Fraud Detection

A Machine Learning project that detects fraudulent bank transactions using data analysis, feature engineering, and classification models. The project includes data preprocessing, model training, evaluation, and explainable AI techniques for better prediction transparency.

## 🚀 Features

- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Feature Engineering
- One-Hot Encoding
- Fraud Detection using Machine Learning
- XGBoost Model Training
- Model Serialization with Pickle
- Explainable AI using SHAP

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- SHAP
- Matplotlib
- Seaborn
- Plotly

## 📊 Workflow

Dataset → Data Preprocessing → Feature Engineering → Model Training → Evaluation → Fraud Prediction → SHAP Explainability

## 🎯 Objective

To build an intelligent fraud detection system that helps identify suspicious financial transactions and supports better decision-making through explainable machine learning.

## 🔮 Future Improvements

- Real-time Fraud Detection
- Flask/FastAPI Deployment
- Interactive Dashboard
- Cloud Deployment (AWS/Azure)
- Live Transaction Monitoring
